## Taught

1. **`match` is structural equality, not an assertion helper.** `match actual == expected` compares
   the whole structure; key order is irrelevant, an extra key is a failure, array order matters.
2. **Trap:** `'#[]'` means "any array" and **passes on `[]`**. It is not a non-empty check. Use
   `'#[N]'` for exact size or `'#? _.length > 0'` for a guard.
3. **`contains` is the subset operator.** `==` breaks the day the provider adds a field; `contains`
   asserts only the keys you care about. `contains only` ignores order, `!contains` asserts absence.
4. **Fuzzy markers are the schema language:** `#string`, `#number`, `#null`, `#present`,
   `#notpresent`, `#ignore`, `#regex`, plus `##` for "key may be absent".
5. **`match each`** applies one assertion to every element — the one-line answer to "validate the
   whole collection, not just element 0".
6. **The diff is the pitch.** A failed `match` prints the path and the reason
   (`$[1].email`, "actual does not contain key"), which `assertEquals(json1, json2)` cannot.
