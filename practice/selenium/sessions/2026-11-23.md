2. Parallel is disabled (`DataProvider(parallel = false)`).
3. No test-data layer / API seeding — every scenario drives state through the UI.
4. `ThreadLocal` driver exists but has never been exercised with more than one thread.

## Taught

1. **What "enterprise" means concretely** — a pipeline that builds, runs headless, and keeps reports;
   plus the five layers (runner → hooks → driver → pages → steps) behind it.
2. **CI anatomy** — trigger, job, JDK + Maven cache, headless run, artifact upload with `if: always()`.
3. **Why headless is not optional** — GitHub runners have no display; the flag lives in config, so CI
   only passes a `-D` and the code stays unchanged.
