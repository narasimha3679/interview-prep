# Intermediate Coding Drills

Problems that show up in SDET/backend interviews. Two starter files are included; use the rest as
practice and add your own runnable `main()`.

| Problem | Technique |
|---|---|
| Find two indices that add to a target | HashMap |
| Longest substring without repeating characters | Sliding window |
| Merge overlapping intervals | Sort + scan |
| Group words that are anagrams | Sorted key / frequency key |
| Top K frequent elements | HashMap + heap/bucket |
| Search in a sorted array | Binary search |
| Reverse a linked list | Pointers |
| Balanced brackets | Stack |

## How to practice

1. Write the brute-force solution and state its complexity.
2. Improve it and explain the trade-off.
3. Test edge cases: empty, one element, duplicates, negative, overflow.
4. Say the complexity out loud.

## Run

```bash
javac TwoSum.java
java TwoSum
```
